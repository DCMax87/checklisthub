API usage (this session)

        

          

            Shows how much this hub talked to Trello this session. Closing the
            hub clears it. Shared Power-Up API keys are limited to about
            300 request units / 10s; your member token about
            100 / 10s. Use Refresh day to day; wait a
            minute if things slow down.
          

          

          

        

        

          
        

      

    


    

      

      

        
Privacy & data

        

          

            Checklist Hub is a read-only Trello Power-Up. It helps you review
            checklist work across boards; completing items stays in Trello.
          


          
How your data is handled

          
    
            
  • 
              After you authorize, the hub talks to
              Trello’s API only (api.trello.com)
              with your token — from your browser.
            
    • 
            
  • 
              Board, card, and checklist contents are kept
              in memory while this hub is open. They are not
              written to cookies, localStorage, or sessionStorage.
            
    • 
            
  • 
              Closing the hub clears that data. View checklists again next time.
            
    • 
            
  • 
              Compact UI preferences (board ids, saved views, assignee ids,
              density, theme) may be stored in
              cookies on this host only (~180 days).
            
    • 
            
  • 
              Your OAuth token is stored by Trello in Power-Up
              plugin data — not by a separate Checklist Hub server. Use
              Disconnect in the footer to clear it from this
              Power-Up.
            
    • 
          


          
No third-party exfiltration

          

            This Power-Up does not send your Trello board, card,
            or checklist contents to Checklist Hub authors, analytics vendors, or
            other third-party APIs. There is no app backend that receives your
            workspace data.
          


          
Third-party resources loaded by the page

          

            The hosted page may load the following so the UI and Power-Up
            connector work. They do not receive your checklist payloads from this
            app:
          

          
    
            
  • 
              Trello Power-Up client —
              p.trellocdn.com/power-up.min.js (Atlassian/Trello),
              required to run inside Trello.
            
    • 
            
  • 
              Trello REST API —
              api.trello.com, only after you authorize, to read the
              boards and cards you can access.
            
    • 
            
  • 
              Fonts — Jost and Material Symbols Outlined from
              Google Fonts (fonts.googleapis.com /
              fonts.gstatic.com). Your browser may share IP and
              user-agent with Google when fetching fonts.
            
    • 
          

          

            Prefer hosting this Power-Up on a trusted HTTPS origin with Allowed
            Origins locked to that host. English UI only.
          


          
Disclaimer

          

            Checklist Hub is provided as-is. It does not modify Trello cards.
            CDN availability, Trello API rate limits (per API key and per token),
            and browser cookie rules are outside the control of these static
            files.
